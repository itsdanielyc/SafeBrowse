# Product media

The project owner supplied these assets for public distribution:

- `product-overview.png`: original 2048 × 1152 product overview artwork, copied without modification.
- `safebrowse-demo.mp4`: original 2560 × 1440, 60 fps product animation (31 seconds), copied without modification.

The README's GitHub-hosted player uses a 1920 × 1080, 30 fps H.264/AAC derivative of the same animation to fit GitHub's free-account attachment limit. The original video above remains downloadable.

The animation uses demonstration content and illustrates the product experience. It is not a recording of every supported capture tool or proof of a security boundary. Capture behaviour varies by recorder and sharing mode; see [SECURITY.md](../../SECURITY.md).
